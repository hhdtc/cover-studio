Files copied unmodified: `demo.html`, `nerv-ui.css`, `components/*.html`,
`components/crt-effects.css`.

Served locally so the catalogue can show the reference implementation without
depending on the upstream repo staying reachable. Fonts load from Google Fonts
(Noto Serif Display, JetBrains Mono, Saira Extra Condensed, Shippori Mincho B1),
so these pages need network access to look right.

No franchise artwork, logos or marks are included: every page is CSS-and-DOM
only. The style is an interpretation of a fictional console aesthetic.
